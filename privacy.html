Privacy policy

Last updated: 6 November 2026 (added: manage videos, post comments)

FactFlow is a personal tool. Only the owner of the connected YouTube channel uses it. It is not offered to other people.

Data FactFlow accesses

When the owner signs in with Google, FactFlow asks for these permissions:

  • Upload videos (youtube.upload): to publish videos to the owner's channel.
  • View the YouTube account (youtube.readonly): to read the channel name and video statistics.
  • Manage YouTube videos (youtube): only to change the visibility (public, unlisted or private) of videos FactFlow uploaded, when the owner asks for it.
  • Manage comments (youtube.force-ssl): only to post one comment, as the channel, under each video FactFlow uploaded. FactFlow does not read, edit or delete other people's comments.
  • View YouTube Analytics (yt-analytics.readonly): to read watch-time and retention numbers for the videos FactFlow uploaded.

How the data is used and stored

  • The data is used only to upload videos and to measure how they perform.
  • The sign-in token and the statistics are stored only on the owner's own computer.
  • FactFlow does not sell, share or transfer Google user data to anyone.
  • FactFlow does not use Google user data for advertising.
  • FactFlow does not use Google user data to train AI or machine-learning models.

FactFlow's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

FactFlow uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Removing access and data

The owner can remove FactFlow's access at any time at myaccount.google.com/permissions. Deleting the local FactFlow folder deletes all stored data.
